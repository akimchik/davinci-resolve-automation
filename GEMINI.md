# Antigravity Global Project Rules

## Architecture and Design Principles
- Do NOT make snap decisions like creating custom scripts or fast solutions that break project logic or act as obvious workarounds.
- Always stick to the project's established architecture and design patterns.
- When updating or modifying workflows, strongly rely on the context of the topic. DO NOT invent new "bicycles" (custom scripts or redundant wrappers) as this codebase already has established tools for these tasks.
- Modifying actual existing codebase files is vastly preferred over writing brand-new one-off scripts.
- Ensure any code modifications are done properly and thoroughly in alignment with existing codebase patterns.
